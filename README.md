# GameSiteV2
Il s'agit d'un projet de lycée en permière, les images étaient hébergées sur Glitch qui a fermé et ne sont donc plus disponiible.
Un petit site de jeux web réunissant trois jeux classiques : le morpion, pierre-papier-ciseaux et Snake. Chaque jeu dispose de sa propre page et se joue directement dans le navigateur.

[Ouvrir GameSiteV2](https://breizhimic.github.io/GameSiteV2/)
